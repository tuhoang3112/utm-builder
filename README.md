# TM UTM Builder

Công cụ tạo link UTM cho Tomorrow Marketers theo Quy chuẩn UTM của công ty.

- Chọn kênh, nhập chiến dịch, loại nội dung, tiêu đề và khóa học; link được ghép tự động.
- Mọi mã viết thường, không dấu, nối bằng dấu gạch dưới.
- Lịch sử link vừa tạo chỉ lưu trên trình duyệt của từng người.

## Cập nhật danh sách

Danh sách kênh, loại nội dung và khóa học nằm ở đầu thẻ `<script>` trong `index.html`
(`CHANNELS`, `PREFIXES`, `PRODUCTS`). Thêm dòng mới vào đó rồi commit là xong.
